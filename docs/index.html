What this tool does not do

  • It does not detect bias it has not been told to look for, including racial, disability and socioeconomic bias.
  • It cannot verify the data entered. A wrong h-index produces a confident wrong flag.
  • Gender is recorded as entered by the chair, not as self-identified by the candidate.
  • It has no memory across sessions, so it cannot yet show your committee's patterns over time.
  • The chair knows which seat link went to which person, but never learns which ballot came from which seat.
